# Author profile

The defaults shipped with the skill. To change one, tell the skill ("default to RFS", "always seat
the auditor"). It then writes your own `profile.md` next to this file, which is used in place of this
one and is ignored by git.

- **Field:** finance
- **Target journals:** Journal of Finance (JF), Review of Financial Studies (RFS), Journal of Financial Economics (JFE)
- **Default target:** none set. Ask which of the three for each paper, since fit differs.
- **Default depth:** standard
