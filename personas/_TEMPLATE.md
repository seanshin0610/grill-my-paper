How to write a persona that earns a seat.

A persona is worth adding only if it finds things the existing seats would not. Tone does not do that
("a harsh reviewer", "a friendly reviewer"). These do:

1. A distinct mandate: one question that only this reviewer is responsible for answering.
2. A distinct way of reading: different information (restricted pages, web search, tables first) or
   different attention (reads for the mechanism, reads for the aggregate magnitude).
3. A deliverable of its own: a table, a paragraph, or a calculation that no other seat produces. This
   is what the editor will actually use.
4. Named traps: the specific ways this kind of reviewer goes wrong.
5. A role in cross-examination: what this lens can settle that the others cannot.

Explain why each instruction matters. A reviewer who understands the reason handles the cases the
instructions did not anticipate. Write {parameter} wherever the editor should fill in a blank.

Keep it under about 70 lines. Delete this comment in the finished persona.
